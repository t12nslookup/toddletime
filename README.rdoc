== Toddletime

The application uses Ruby 4.0.10 (managed by rbenv), Rails 8.1 and PostgreSQL.
Install the Ruby version in +.ruby-version+, then run:

  bundle install
  bin/rails db:prepare
  bin/rails server

Configure PostgreSQL as described in +config/database.yml+. In production,
set +DATABASE_URL+ and configure the application's credentials and mail service.
Rails 7.0 configuration defaults are intentionally retained to preserve existing
behavior, including existing signed and encrypted data.

Run the tests and lint with:

  bin/rails test
  bundle exec rubocop

Refresh model and route annotations after schema or route changes with:

  bundle exec annotaterb models -k --simple-indexes
  bundle exec annotaterb routes

Generate a Mermaid entity relationship diagram with +bundle exec rake erd+.
For PDF output, install Graphviz and run:

  bundle exec rake erd generator=graphviz filetype=pdf
